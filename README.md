# Random Quote Generator

A simple web application that generates random inspirational quotes using a public Quotes API. Users can generate new quotes, copy quotes to the clipboard, share them on Twitter, and switch between light and dark themes.

## Features

- Generate random quotes instantly
- Display quote author information
- Copy quotes to clipboard
- Share quotes on Twitter
- Light/Dark mode toggle
- Responsive and modern UI

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Quotable API
